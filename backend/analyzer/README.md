# analyzer

Python 분석 서비스 (작업 예정). FastAPI로 시작합니다.

## API 초안

```
POST /analyze
{ "text": "어제 밤새 쇼츠만 봤어요" }

200
{ "category": "dopamine", "keyword": "쇼츠", "risk": false }
```

- 사용자 원문은 저장하지 않습니다. 로그에도 남기지 않습니다
- `keyword` 는 사전에 있는 단어만 돌려줍니다. 사용자가 쓴 임의의 말이 신부 답변에 들어가지 않게 하기 위해서입니다
- 매칭되지 않으면 `category: "generic"`
