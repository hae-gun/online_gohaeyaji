# backend

| 서비스 | 언어 | 역할 |
|---|---|---|
| `realtime-server/` | Java, Spring Boot | WebSocket 연결, 채널 배정, 고해소 점유와 회수, 상태 브로드캐스트, 답변 조합 |
| `analyzer/` | Python | 고해 텍스트를 받아 카테고리, 매칭 키워드, 위험 여부만 돌려줌 |

## 역할 경계

| 담당 | realtime-server | analyzer |
|---|---|---|
| 연결, 채널, 고해소 점유 | O | |
| 위기 키워드 1차 검사 | O | |
| 형태소 분석, 카테고리 분류 | | O |
| 매칭 키워드 추출 (사전 단어만) | | O |
| 답변 템플릿 선택, 음성 파일 결정 | O | |

어떤 답변을 낼지는 realtime-server 한 곳에서만 정합니다. 답변 문구를 한 곳에서 관리하기 위해서입니다.

## 장애 원칙

- analyzer 호출은 짧은 타임아웃, 넘으면 범용 답변
- 연속 실패 시 서킷 브레이커로 호출 중단 후 범용 답변
- 위기 키워드 검사는 analyzer가 죽어도 동작해야 하므로 realtime-server에도 둔다

사용자 입장에서는 analyzer가 죽어도 신부님이 조금 덜 맞춤형으로 대답할 뿐, 서비스는 그대로 동작해야 합니다.
